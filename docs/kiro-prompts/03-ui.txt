CORE API (import from './core/index.mjs' relative to src/ui files: '../core/index.mjs'):
- analyze(text) -> { lines:[{text,index,type,bodyStart}], findings:[{id, ghostId, lineIndex, start, end, match, severity, message, suggestion}], score:0-100, band:'Purified'|'Restless'|'Haunted'|'Cursed', stats:{requirementLines, userStories, hauntedLines, byGhost:{[ghostId]:count}} }
  line.type in 'blank'|'heading'|'code'|'meta'|'userStory'|'requirement'|'note'|'prose'. finding.suggestion = the full rewritten LINE after exorcising that finding (use it for the before/after diff).
- GHOSTS: array of 7 {id, name, color, severity, silhouette ('wisp'|'poltergeist'|'wraith'|'ghoul'|'banshee'|'soul'|'beast'), summary, why}; GHOST_BY_ID map.
- exorcise(text, finding) -> new text; exorciseAll(text) -> new text (idempotent).
- toKiroRequirements(text) -> markdown string; toEars(line) -> string.
- bandInfo(score) -> {name, max, blurb}.
